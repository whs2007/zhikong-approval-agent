# 「智控」企业级智能工作流平台 — 测试方案与验收

> 文档版本：v1.0
> 前置文档：《01-需求分析说明书》《04-API 接口设计》《06-开发计划与里程碑》

---

## 1. 测试策略

| 层级 | 类型 | 工具 | 范围 |
|------|------|------|------|
| 单元 | 纯函数/Provider | pytest | 风险分级、路由函数、Embedding、审计写入 |
| 集成 | 工作流端到端 | pytest + LangGraph app | 提交→分析→审批/执行→重试→结束 |
| 接口 | REST API | httpx.AsyncClient + FastAPI TestClient | 鉴权、提交、审批、审计查询 |
| 恢复 | 跨天/重启 | pytest（新进程+同 DB 文件） | thread_id 恢复 |
| 审计 | 留痕完整性 | pytest 断言 audit_log 行 | 事件覆盖 |

---

## 2. 核心测试用例（TC）

| 编号 | 场景 | 步骤 | 期望 |
|------|------|------|------|
| TC-01 | 低风险自动执行 | 提交 amount=3000 → 查询状态 | current_phase=done, execution_result=success, 无审批 |
| TC-02 | 高风险人工审批 | 提交 amount=300000 → 暂停(approve) → 审批通过 → 恢复 | done, approved, 有 final_report |
| TC-03 | 审批驳回 | 提交高风险 → 驳回 | 流程结束, 不执行 |
| TC-04 | 图级别重试 | Executor 模拟失败 → 自动重试至成功/超限 | retry_count 递增, 每次有快照与日志 |
| TC-05 | 跨天恢复 | 提交高风险 → 进程退出 → 新进程用同 DB + thread_id 审批 | 状态恢复, 流程完成 |
| TC-06 | 审计留痕 | 完成 TC-02 → 查 audit_log(thread_id) | 含 SUBMIT/RISK/PAUSED/DECISION/DONE |
| TC-07 | 鉴权 | 无 JWT 调审批接口 | 401 |
| TC-08 | 越权 | applicant 调审批接口 | 403 |
| TC-09 | RAG 检索 | 提交采购 → 查看 knowledge_context | 含命中规章制度片段 |
| TC-10 | 指标/健康 | GET /health, /metrics | 正常返回 |

---

## 3. 验收标准映射（对应 SRS §7）

| SRS 验收项 | 对应 TC |
|------------|---------|
| 低风险自动执行+报告+审计 | TC-01, TC-06 |
| 高风险暂停→审批→恢复+审计 | TC-02, TC-06 |
| 失败重试至成功/超限 | TC-04 |
| 重启恢复不丢 | TC-05 |
| 无 JWT → 401 | TC-07 |
| 管理员查审计并导出 | TC-06 + /audit/export |
| pytest 全绿 | 全部 |

---

## 4. 执行与报告
- 命令：`pytest -q`（位于 `zhikong/` 根）。
- 输出：终端摘要 + `tests/report.xml`（可选）。
- 报告纳入《过程审计报告》附件。

---

## 5. 非功能验证（抽查）
- 默认离线启动时间 < 10s（无模型下载）。
- 单请求分析耗时（规则模式）< 1s。
- 审计写入失败不影响主流程（降级日志可见）。
