# 15. 同类项目对标与借鉴

> 目的：证明本项目的技术选型不是"拍脑袋"，而是**横向对标后的取舍**。
> 对标对象来自 GitHub 上同类型（LangGraph + FastAPI + Human-in-the-Loop + 企业审批）项目。

|---|---|---|

## 2. 前端设计对标

| 对标项目 | 设计特征 | 本项目落地方式 |
|---|---|---|
| `NhanPhamThanh-IT/Admin-Dashboard-Template` | 统计卡（StatBox）+ 多图表 + 可折叠侧边栏 + 暗/亮主题 | ✅ 4 张统计卡 + 侧边栏 5 视图 + 双主题 |
| `Murzuq/Zuq-Admin-Dashboard` | 玻璃拟态（backdrop-blur）、lucide 图标、暗色优先 | ✅ 玻璃拟态卡片 + 内联 SVG 图标（lucide 风格） |
| Windmill Dashboard | **无障碍优先**（屏幕阅读器、focus 管理、键盘导航）、Heroicons | ✅ 语义化标签、`aria-current`/`aria-label`、`focus-visible` 焦点环、表单可键盘提交 |
| `marleyDip/NextJS-Admin-Dashboard-ShadCN` | TanStack Table（排序/分页/筛选/行操作）+ Recharts | ✅ 原生实现**可排序 + 搜索 + 行内操作**表格（零依赖，不引 React/图表库） |
| `DashboardPack/dashio-template` | 暗/亮模式 + 运行时配色切换 | ✅ 主题切换 + localStorage 记忆 |

**关键约束**：本项目前端是**单文件原生 HTML、零依赖、可离线**（评审中"零外部 API Key 也能完整跑通演示"是该项目的核心卖点）。
因此没有引入 React / Tailwind / Chart.js —— 图表用手写 SVG 环形图，表格用原生排序实现，
换取的是：`pip install` 后无需 `npm install` 即可看到完整界面。

## 3. 借鉴带来的实际收益（可量化）

| 借鉴项 | 改进前 | 改进后 |
|---|---|---|
| 混合检索 | 检索准确率评测 **70%**（top-1 排错条款、无关查询也硬凑上下文） | **100%**（19/19） |
| 审批升级 | `APPROVAL_ESCALATE_HOURS` 定义了无人消费 | 超时/升级可观测 + 审计留痕，可据此告警 |
| 前端 XSS | 旧版多处 `innerHTML` 直接拼外部数据 | 全部经 `esc()` 转义 |
| 前端指标面板 | P1-3 后 `/metrics` 改为 Prometheus 文本 → **面板已坏** | 改调 `/metrics/summary`，恢复正常 |

## 4. 仍未对标/列为 P2 的项

- 真实 LLM 接入后的输出一致性评测（需 API Key，与"离线可跑"定位冲突）
- 文档/租户级检索作用域隔离
- 前端轮询自动刷新、WebSocket 推送
- 按钮级 RBAC、Token 无感刷新
- 时间戳统一 UTC（当前本地 naive 时间，涉及存量数据迁移）
